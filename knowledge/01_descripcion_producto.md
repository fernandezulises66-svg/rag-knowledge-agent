# Descripción del producto Nubira

> Nubira es una empresa y un producto ficticios, creados únicamente con fines demostrativos para este proyecto de portafolio. Cualquier parecido con empresas o productos reales es coincidencia.

## ¿Qué es Nubira?

Nubira es una plataforma SaaS (software como servicio) de gestión de proyectos y colaboración en equipo, diseñada para pequeñas y medianas empresas (pymes). Permite organizar proyectos, tareas, la comunicación interna del equipo y automatizaciones simples de flujo de trabajo, todo desde el navegador web.

## Clientes objetivo

Nubira está pensada para equipos de entre 1 y 200 personas en pequeñas y medianas empresas de sectores como servicios profesionales, agencias de marketing, estudios de diseño, equipos de desarrollo de software y consultoras. No está diseñada específicamente para grandes corporaciones con miles de usuarios.

## Funciones principales

### Proyectos

Los usuarios pueden crear proyectos para agrupar tareas relacionadas. Cada proyecto tiene un nombre, una descripción, una fecha de inicio opcional y miembros asignados.

### Tareas

Dentro de cada proyecto, los equipos pueden crear tareas con:

- título y descripción,
- fecha límite,
- nivel de prioridad (baja, media, alta),
- persona responsable,
- subtareas,
- etiquetas para clasificación,
- comentarios para discusión interna.

### Colaboración en equipo

Nubira permite comentar tareas, mencionar a compañeros con "@nombre" para notificarlos directamente, y compartir actualizaciones dentro de cada proyecto. Todo el historial de comentarios queda guardado en la tarea correspondiente.

### Automatizaciones de flujo de trabajo

Nubira incluye automatizaciones simples basadas en la lógica "cuando ocurre X, entonces hacer Y". Por ejemplo: "cuando una tarea se mueve a la columna 'Hecho', notificar por correo a la persona responsable del proyecto". Las automatizaciones se configuran desde el panel de cada proyecto. Los límites de automatizaciones activas y de ejecuciones mensuales varían según el plan contratado (ver `02_planes_y_precios.md`).

### Archivos adjuntos

Los usuarios pueden adjuntar archivos a las tareas y comentarios. El tamaño máximo permitido es de 25 MB por archivo adjunto.

### Notificaciones

Nubira envía notificaciones dentro de la aplicación y por correo electrónico cuando: se asigna una tarea, se menciona a un usuario, se acerca una fecha límite, o se completa una automatización relevante. Las preferencias de notificación pueden ajustarse por usuario.

### Acceso web compatible

Nubira funciona completamente desde el navegador web. Los navegadores compatibles son las dos versiones más recientes de Google Chrome, Mozilla Firefox, Microsoft Edge y Safari. El diseño es responsivo y puede usarse desde el navegador de un teléfono móvil o tableta.

## Limitaciones básicas del producto

- No existe una aplicación móvil nativa para iOS o Android; el acceso móvil es únicamente a través del navegador.
- El tamaño máximo de archivo adjunto es de 25 MB.
- Los límites de almacenamiento, número de usuarios y automatizaciones dependen del plan contratado.

## Funciones que Nubira NO ofrece actualmente

Para evitar confusiones, Nubira deja claro que las siguientes funciones **no** forman parte del producto en este momento:

- Nómina o gestión de sueldos (payroll) nativa.
- Contabilidad o facturación contable avanzada.
- Videoconferencia integrada.
- Un pipeline de ventas tipo CRM (gestión de oportunidades comerciales).
- Inicio de sesión único (SSO/SAML) para autenticación empresarial.
- Aplicación móvil nativa para iOS o Android.

Estas funciones podrían evaluarse en el futuro, pero no están disponibles ni documentadas como parte del producto actual.
